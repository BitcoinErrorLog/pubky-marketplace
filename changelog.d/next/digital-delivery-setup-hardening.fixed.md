Setting a digital file is sturdier. If the save gets no reply after the file is uploaded, Shop asks the service again for that save's outcome, deletes the upload only when the service had refused it, and keeps it when the save went through. A file this browser can't encrypt now says so ("This browser couldn't encrypt the file, so nothing was uploaded"), and a failed save after upload no longer reads as a homeserver refusal. A purchase whose file type isn't one the service accepts is refused before download rather than saved with that type.
