Private messages stay safe with Shop open in several tabs: only one tab at a time sets up messaging, sends, receives or connects on a conversation, and each tab picks up where the others left off, so every tab uses the same messaging key and it is the one others can find. A browser that cannot coordinate its tabs pauses private messages instead of sending. Signing out in one tab stops private messages in the others instead of letting them save anything that could not be opened again.
